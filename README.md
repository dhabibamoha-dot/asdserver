# سيرفر التفعيل الخاص بـ Multi Tabs Controller

سيرفر صغير (Node.js فقط، بدون Express) بيوفر:
- تسجيل دخول بكود لمستخدمي الأداة (`/api/auth/login`, `/api/auth/validate`)
- لوحة تحكم أدمن على `/admin` لإنشاء/تمديد/إلغاء الأكواد وتحديد مدتها وصلاحياتها
- اتصال حقيقي بـ MongoDB (لما تحط `MONGO_URI`)، وإلا بيشتغل بملف JSON محلي للتجربة بس

## 1) رفعها على استضافة مجانية

أي استضافة بتدعم Node.js تمام (المشروع من غير أي dependency تقريبًا غير `mongodb`):

- **Render** (free web service): اربط الريبو/الفولدر ده، Build Command: `npm install`, Start Command: `npm start`.
- **Railway** / **Cyclic** / **Glitch**: نفس الفكرة — ارفع الفولدر، خليه يشغّل `npm install && npm start`.

### متغيرات البيئة (Environment Variables) اللي تحطها في لوحة الاستضافة

| المتغير       | إجباري؟ | الوصف                                                              |
|----------------|---------|----------------------------------------------------------------------|
| `MONGO_URI`    | لأ (بس لو عايز MongoDB حقيقي) | رابط الاتصال من MongoDB Atlas (مجاني): `mongodb+srv://user:pass@cluster.../mtc` |
| `ADMIN_USER`   | لأ      | اسم مستخدم الأدمن الأول (افتراضي: `admin`)                            |
| `ADMIN_PASS`   | لأ      | كلمة مرور الأدمن الأول (لو سبتها فاضية هيتولد باسورد عشوائي ويتطبع في اللوج أول تشغيل) |
| `PORT`         | لأ      | البورت (أغلب الاستضافات بتحدده هي تلقائي)                              |

> لو مش عايز MongoDB دلوقتي، متحطش `MONGO_URI` خالص — السيرفر هيشتغل بملف JSON محلي
> (`server/data/db.json`) وكل حاجة هتشتغل بالظبط بنفس الشكل، بس البيانات هتكون محفوظة
> على قرص الاستضافة نفسها مش على MongoDB. أي وقت تحط `MONGO_URI` هيتحول تلقائي لـ MongoDB
> الحقيقي من غير ما تغيّر سطر كود واحد.

## 2) أول تشغيل

لما السيرفر يشتغل أول مرة هيطبع في اللوج username/password الأدمن (لو مكنتش حددتهم
في `ADMIN_USER`/`ADMIN_PASS`) — خش بيهم على `https://رابط-سيرفرك/admin`.

## 3) ربط السكريبت بالسيرفر

افتح ملف السكريبت `multi-tabs-controller-v3.user.js` ودوّر على السطر ده قرب الآخر:

```js
const NM_LICENSE_SERVER_DEFAULT = "https://YOUR-SERVER-HERE.example.com";
```

وغيّر الرابط لرابط سيرفرك بعد ما ترفعه (مثلاً `https://mtc-license.onrender.com`).
مش لازم تعدّل السكريبت فعليًا — أول مرة المستخدم يفتح شاشة تسجيل الدخول في الأداة
هيلاقي خانة "سيرفر التفعيل" يقدر يكتب فيها الرابط بنفسه، وهيتحفظ تلقائي في المتصفح
بتاعه. تعديل الثابت ده بس بيخلي الخانة متعبّية افتراضيًا.

## 4) عمل أكواد للمستخدمين

من لوحة الأدمن (`/admin`) → "كود جديد": حدد المدة بالأيام، أقصى عدد أجهزة، وأي
مميزات (صلاحيات) تحب تفعّلها للكود ده (اللاينات، التثبيت، الألوان، رفع الفريمات،
الماكرو، تسجيل الشاشة، تنبيهات الحجم، البروفايلات، مسجل الحزم). التبويبات اللي
مالهاش صلاحية في الكود بتتخفي تلقائيًا من واجهة الأداة عند المستخدم ده.

## 5) أمان مهم

- **السكريبت مايشغلش أي أمر أبدًا قبل ما يتحقق من كود صحيح مع السيرفر** — مفيش
  لوحة، مفيش مفاتيح، مفيش هوكات، لحد ما تيجي استجابة ناجحة من `/api/auth/login`.
- لو السيرفر مش متاح وقت التحقق الدوري (كل 5 دقايق)، الأداة بتقفل نفسها (fail-closed)
  بدل ما تفترض إن كل حاجة لسه شغالة.
- لو لغيت كود من لوحة الأدمن، أي جهاز شغال بيه هيتقفل خلال أقصى 5 دقايق (أو فورًا
  لو عمل أي أمر يستدعي تحقق).
